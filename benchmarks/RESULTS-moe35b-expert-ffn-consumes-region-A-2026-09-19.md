# Qwen3.6-35B-A3B MoE — the routed expert FFN DOES consume region A (2026-09-19)

Goal `mu721yrt-p5wy9i`, step 5 (optimize toward parity). Resolves the wall named in
`RESULTS-moe35b-decode-gap-2026-09-18.md`: the whole-layer ELF (`moe_layer_ctxN.elf`)
does **not** consume the expert pool, so the routed expert FFN must be carried by other
kernels. This note pins down WHICH kernels and their exact arg bindings, by packing region
A vs zeroing it and diffing the output.

## Method

Pack the full expert pool (region A, `npu_pack_moe_expert_pool`, 478,146,560 B — the
unit-interleaved up/gate/down expert image) into the weight BO and run the per-phase expert
ELFs against it once PACKED and once ZEROED. A kernel that reads region A produces non-zero
output only when it is packed.

## Result — both expert-FFN GEMMs consume region A

| kernel | xclbin | ELF | arg order | PACKED | ZEROED |
|---|---|---|---|---|---|
| up_gate (routed GU) | `mm.xclbin` | `up_gate_M256.elf` | weight@5, act@4, out@3 | nz=131072/524288, max=1.13, argmax=327 | nz=0 |
| down (routed D) | `dequant_mm.xclbin` | `down_M256.elf` | weight@5, act@4, out@3 | nz=524032/524288, max=1.03, argmax=1086 | nz=0 |

Both kernels read the expert pool from region A at weight slot 5, take the activation at
slot 4, and write output at slot 3.

## What this means for the integration

The single-launch `MoERuntimeLayerEngine::forward()` runlist currently runs only the layer
ELF (+ host lm_head). The missing routed expert FFN is concrete now:

1. layer ELF (`moe_layer_ctxN.elf`) — attention + GDN + shared expert + norm + router.
2. read the router logits, top-K select the experts.
3. `up_gate` GEMM on `mm.xclbin` (weight@5 = region A, act@4, out@3).
4. SiLU(gate) × up.
5. `down` GEMM on `dequant_mm.xclbin` (weight@5 = region A, act@4, out@3).
6. add to the residual.

The two expert ELFs (`up_gate_M256.elf`, `down_M256.elf`, M=256 shape) already exist in
`/tmp/expert_elfs/` (generated by the region-A probe lane); a decode-shape (M=1/M=8)
variant, or a per-expert batching of these, is the next artifact to produce.
