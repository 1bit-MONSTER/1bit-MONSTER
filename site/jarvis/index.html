Open Knowledge Format

Get Started

Run 1bit JARVIS in 3 commands.

Prerequisites: AMD Strix Halo (Ryzen AI Max+ 395) with NPU drivers installed.

1. Start the NPU backend

sudo flm serve qwen3:0.6b \ --port 52625 --pmode turbo → NPU running at 94 tok/s

The NPU v12 engine runs the model on the XDNA2 NPU. One command, zero config.

2. Start the 1bit JARVIS server

source jarvis-env/bin/activate cd jarvis && python3 server.py → 1bit JARVIS running on :8080

Python FastAPI server. Orchestrator, agent, voice I/O, RAG, knowledge base — all in one process.

3. Open the web UI

open http://localhost:8080/chat → 1bit JARVIS interface loads

Full chat UI with streaming, voice, vision, and file upload. Works in Chrome, Firefox, Safari.

Mobile access

curl -fsSL 1bit.monster/mobile.sh | sh → ngrok tunnel + QR code

Expose 1bit JARVIS via ngrok. Scan the QR code with 1bit JARVIS Mobile (iOS/Android) to chat from anywhere.
