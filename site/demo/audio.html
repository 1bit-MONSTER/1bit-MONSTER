Speech-to-Text — Whisper-V3-Turbo

STT Whisper-V3-Turbo

1.5s

Latency to first word. Real-time transcription on NPU. Handles multiple languages, noisy environments, and technical vocabulary.

STT Model Details

NPU · ~15W

Runs entirely on the XDNA2 NPU. No cloud dependency. No data leaves the device. ~1.5s for first word, then streams continuously.

# Whisper STT on NPU — real-time transcription STT Input: [ 16kHz PCM audio stream ] STT Model: Whisper-V3-Turbo (NPU) STT Latency: ~1.5s first word STT Output: "Hello, how can I help you today?"

Text-to-Speech — Piper TTS

TTS Piper TTS

50ms

Latency to first audio sample. Edge TTS engine running locally. Multiple voices available. No cloud API calls.

TTS Voice Models

~50ms · CPU

Piper runs on CPU (not NPU). ~50ms latency means the voice starts speaking almost instantly after the LLM generates the first token.

# Piper TTS on CPU — instant voice synthesis TTS Input: "The capital of France is Paris." TTS Model: Piper (CPU, ~50ms latency) TTS Voice: en_US-lessac-medium (default) TTS Output: [ 22kHz PCM audio stream → speaker ]

Example: Voice Query "What is the capital of France?"

🎤 Mic input: "What is the capital of France?" (spoken, 1.2s audio)
📝 STT Whisper transcribes → "What is the capital of France?"
🧠 NPU Qwen3 infers → "The capital of France is Paris." (6 tokens, 62ms)
🔊 TTS Piper speaks → "The capital of France is Paris." (~0.5s audio)
✅ Total: ~2s from spoken question to spoken answer. Fully local. No cloud.
