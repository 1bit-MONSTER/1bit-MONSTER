⚙️ How to Run

  # Build
  git clone https://github.com/1bit-MONSTER/1bit-MONSTER
  cd 1bit-MONSTER
  cmake -B build -G Ninja -DCMAKE_HIP_ARCHITECTURES=gfx1151
  cmake --build build --target zaya_server -j8

  # Run fused inference (NPU + GPU)
  cd engine/fusion
  ./zig-out/bin/fused-engine \
    -m /path/to/model.q4nx \
    --npu-engine /path/to/npu_engine_universal \
    --tokenizer /path/to/tokenizer.json \
    -n 128 -p "Hello"

  # Run HTTP server
  ./build/zaya_server --port 8088
  curl http://localhost:8088/v1/completion \
    -d '{"prompt":"Hello","n_predict":64}'

📊 Key Design Decisions

DecisionWhy
Pure C++ (Zero Python)No runtime overhead, no interpreter, no subprocesses
Protobuf-free ONNX loaderZero dependencies — reads protobuf wire format directly
NPU subprocess protocol66 tok/s on NPU via binary protocol (4× faster than FLM bridge)
Vulkan GPU attentionCross-platform, no CUDA dependency, works on AMD/NVIDIA/Intel
Batch NPU opcodes (20-23)Cuts 84 round-trips to 3 — 28× fewer NPU worker calls per token
Agent WatchdogClosed-loop adaptation: thermal → shift load, failures → disable backend, stable → re-profile
Q4NX formatSame as safetensors but with size prefix — simple, fast, no protobuf
