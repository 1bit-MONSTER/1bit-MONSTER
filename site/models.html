94% HF coverage, one engine

Coverage is defined at the architecture class, not per checkpoint. A class that works brings its whole family with it — including checkpoints that did not exist when the class was written. Roughly 50 classes cover the long tail of what HuggingFace hosts; 19 are live.

Three components make a new class cheap: the registry (detection and metadata), the kernel path (reused ops, quant-aware), and the validation harness (numerical comparison against the reference). All three are proven.

Formats

GGUF, ONNX, and the native 1BP format are read directly. Architecture detection is automatic; there is no per-model configuration file and no conversion step to babysit.
